# xxm

A lightweight JAX implementation of SLDS inference routines, inspired by [`ssm`](https://github.com/lindermanlab/ssm) and [`dynamax`](https://github.com/probml/dynamax).

## Installation

```bash
pip install -e .
```

## Development

Run tests with:

```bash
pytest
```

Format and lint with:

```bash
ruff format .
ruff check .
```

## Status

Early development.
